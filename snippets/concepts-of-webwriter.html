Concepts of WebWriter

WebWriter brings text, media, and interactive widgets together in HTML documents. This map introduces the ideas behind authoring and using those documents.

Return to the map and open a concept to explore it. Follow the arrows to see how the concepts relate.

  • Documents hold the learning content, and themes give it a consistent appearance.
  • Widgets add interaction, and snippets provide ready-made examples.
  • Live sessions let participants use the content together, with shared data where a widget supports it.

Documents

A WebWriter document combines ordinary HTML content, such as headings, paragraphs, lists, and images, with interactive widgets.

Authors arrange and edit the content. Readers explore the resulting material and use the interactions that its widgets provide.

Widgets

Widgets add activities and visualizations to a document. Examples include quizzes, simulations, diagrams, and this advance organizer.

Each widget supplies its own controls. Authors configure it in edit mode; readers use the interactions offered in reading mode.

Live sessions

A live session connects a host with participants who use a document. Widgets that support sessions can collect responses and let the host review them.

The available participant actions depend on the widget and the permissions chosen by the author or host.

Themes

A theme gives a document a consistent visual style through choices such as fonts and colors. Widgets that support theming can follow those choices too.

The content stays the same when its presentation changes.

Snippets

A snippet is a prepared piece of content that an author can insert into a document. It can contain a configured widget, example data, and supporting text.

This concept map is a snippet. After inserting it, an author can rename concepts, move them, change relations, and edit these explanations.

Shared data

Widgets that support sharing can keep data for one participant, for a group, or for everyone in a session.

  • Individual data lets participants work on their own responses.
  • Group data supports a shared activity within a group.
  • Data shared with everyone supports a common result.

The available sharing choices depend on the widget.
